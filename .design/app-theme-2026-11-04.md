# App theme — November 4, 2026

The user requested that the working app resemble the new luggage-tag landing page. This supersedes the earlier DESIGN.md instruction to keep that direction exclusive to the public website.

## Implementation

- Shared local font definitions between public and app surfaces. Barlow remains the readable body face; Barlow Condensed carries controls, headings and metadata; Antonio carries trip titles, balances and real confirmation codes.
- Aligned light/dark canvas, surface, ink, muted and coral tokens with the website. Kept accessible ink text for coral primary actions and retained semantic status/category colors.
- Added the app translation in `src/styles/app-theme.css`, scoped through the root layout's `.app-world`. The public landing composition remains separate.
- Desktop trips sit on a rounded paper sheet against ocean ink. The workspace rail uses dashed divisions and an ink selection marker. Mobile retains full-width content and existing bottom navigation.
- Applied flat ink outlines to shared cards, row groups, controls and dialogs; dashed rules group records and separate itinerary entries. Primary actions and floating add buttons use coral; selected switches and vote choices use ink.
- Updated overview, plan, vote, money and document details: framed destination art, a coral-edged next step, condensed time columns, a balance stub, perforated document edges and prominent actual confirmation codes.
- Updated the browser theme color and installed-app launch background to the new paper palette. No new dependencies, data model changes or navigation changes.
