# Production component migration map

Adapters render upstream compiled components. No component source was copied/swizzled. Existing feature calculations and repositories remain unchanged.

| Existing primitive | Actual Astryx foundation | Adapter/API and risk | Migrated production callers | Remaining exceptions |
| --- | --- | --- | --- | --- |
| Button | `@astryxdesign/core/Button` | label from visible children or explicit aria-label; danger -> destructive; native type/disabled/ref; aria-busy -> isLoading. Stowaway theme owns styles; old Daisy classes removed. Icon content gets an explicit inline layout. | All shared Button callers, including Create, Invite, vote option entry, expense/task saving, preparation/retry and Quick Add | Native bespoke icon buttons, score buttons and toast actions remain. LinkButton is still a Router anchor. |
| Card | `@astryxdesign/core/Card` | upstream div replaces section; named regions preserved; Stowaway heading/footer anatomy retained. Removed old shared base Card styling and Daisy class. | Trip day preview, join welcome, roster/PeopleCard, Money personal/group sections, forms/settings and other shared Card callers | Rows, timeline, map overlays, travel tickets and public luggage-tag compositions are intentionally custom. |
| Segmented | `SegmentedControl` + `SegmentedControlItem` | upstream radio pattern, controlled value; only declared option values escape adapter. Rich labels use the documented icon/hidden-label path. 44px minimum in theme. | Temperature preference, access mode, Money currency view and shared Segmented consumers | Appearance uses tested native radios; Plan/Vote custom view switches still use ui-segmented and now have 44px targets. |
| Controlled text Input/Field | `TextInput`, internally composing Astryx `Field` | TextField maps native required/disabled, maxlength/autocomplete and a 44px editable target. Existing Field automatically composes it for one controlled text/email/search/tel/url/password Input without custom size/styles, translating the original native change event, name/ref, hints and keyboard traits. | Create, expense description/amount, itinerary name, task title, decision confirmation; other eligible shared Field callers | Composite, uncontrolled, date/file/number, custom sizing/styles, select and textarea stay native. These are explicit compatibility boundaries. |
| TravelerLink | `@astryxdesign/core/Link` + LinkProvider | href -> Router to; forwards ref/state; decorative avatar hidden from accessible name. | PeopleCard roster, tasks, traveler references and balance rows using TravelerLink | Existing nav/day links and LinkButton retain native Router behavior. |
| Optional details disclosure | `@astryxdesign/core/Collapsible` | trigger/defaultIsOpen, upstream aria-expanded/controls and keyboard activation | Money group details, public planning example, decision linking and booking assignment | Existing native Disclosure remains for advanced forms/settings and error details; consequential owner/deadline/confirmation state stays outside the collapsed forms. |
| Confirmation Dialog | Evaluated `Dialog` + `DialogHeader`; **not retained** | Escape integration did not pass reliably; native control kept with verified bounded exit fallback | Native ConfirmProvider, invite dialogs, sheets and map interactions remain functional | No production Astryx Dialog adoption is claimed. Re-evaluate separately with a minimal repro and nested native-modal tests. |
| Toast | Existing ToastProvider | latest notice stays visible; older ordinary notices remain in Earlier changes; busy/errors stay visible. Undo and dismissal semantics survive navigation. | Tasks and other existing notifications | Upstream Toast deferred until action persistence and undo match. |
| Skeleton / Empty | `@astryxdesign/core/Skeleton` / `EmptyState` | Shared Skeleton retains caller dimensions and ListSkeleton's status label; upstream owns reduced motion. Tasks uses EmptyState's title, description, decorative Stowie and next action. | All collection Skeleton callers; Tasks empty/filter states | Existing compositional Empty supports rich travel content that does not fit string-only title/description props; retain it for those callers. |
| AppShell / MobileNav / BottomSheet | CLI inspected; custom composition retained | would overlap current rail/tabs/scroll/map gesture ownership | none | Preserve Home / Plan / Map / Vote / More and tested custom sheets. |

The usage report is the actual production imports above plus their shared-adapter callers. A dependency, provider, test fixture or showcase page alone is not counted. Built theme artifacts are generated source, not component copies. Scope intentionally avoids replacing every native control in one pass.

Initial-slice source count: **196 shared Button call sites in 81 TSX files; 87 Card call sites in 44 files; 6 Segmented call sites; 2 explicit Create TextFields.** The completion pass extends TextInput through the compatible shared Field path and explicit expense/task/itinerary/confirmation fields, and migrates shared Skeleton and Tasks EmptyState. Source counts are not simultaneous visible controls or individually reviewed screens; the browser matrix exercises actual journeys.
