# Stowaway redesign — October 22, 2026

## Outcome

Rebuilt the public homepage and app entry around a travel-poster / journal
composition, and carried the same colors, typography, controls, and surfaces into
the trip workspace. The website has a photo-led introduction, an interactive
itinerary, contrasting typographic sections, labeled planning examples, offline
preparation, and native FAQs. The application has a compact mobile entry, split
desktop entry, editorial trip titles, refreshed trip cards, a dark desktop sidebar,
and an explicit filled selection on mobile navigation.

The new user request supersedes the earlier reports' locked composition and
restrictions on poster type and accent sections. Existing confirmed requirements
remain: real product evidence, labeled examples, clear offline prerequisites,
keyboard access, readable forms, stable interaction, and no invented bookings or
customer claims.

## Reference

[GSAP Awwwards Website](https://github.com/Fullstack-Empire/GSAP-Awwwards-Website)
was inspected locally at `8a76a36`. Adapted its condensed display scale, rotated
color bands, clip-path reveal, and full-width section rhythm. Stowaway keeps its
existing Motion runtime; no duplicate animation library was added. Font license
and image provenance are recorded in `docs/DESIGN_ASSETS.md`.

## Defects found and resolved during verification

- Mobile welcome poster consumed the primary viewport: replaced by a compact
  introduction at narrow widths, bringing create/join controls forward.
- Enlarged itinerary content grew an implicit grid track and displaced tap
  coordinates: minimum-zero tracks, wrapping headings, and minimum-zero children
  now contain the preview at narrow widths with 200% text.
- A background lazy SVG load raced the itinerary's no-network interaction check:
  the small local brand illustration now loads normally.
- The dark sidebar's generic foreground override washed out the Offline badge:
  sidebar foreground styling now targets only the ordinary sync state, preserving
  the badge's status-specific foreground and background.
- The task test expected a heading superseded by the previous app revision:
  aligned its two expectations with the existing literal “Tasks” screen title.
- The laptop-fold test now verifies the photo-led hero; the interactive preview
  has intentionally moved to its own product demonstration section.

Cloudflare Worker: `trip-hub`; public domain: `https://joinstowaway.app`.

existing OAuth session permits Worker deployment, but the Builds logs endpoint
returns 403, so that older failure's cause was not established from logs.

## Coverage limits

Browser coverage uses Chromium with mobile emulation. Physical-device installation,
other browser engines, screen-reader operation, and real multi-device backend sync
were not newly exercised. This release changes presentation and deployment build
preparation; data and sync behavior are covered by existing unit/browser fixtures.
