# October 8, 2026 release

Voting is a primary trip navigation destination on mobile and desktop. The trip
overview leads with open group decisions, remaining personal votes, and a clear
start-a-vote action. Mobile expenses remain accessible from More. Existing vote
URLs remain compatible.

Completes the website-entry polish: desktop trip shell, overview and invites,
accessible confirmations, actionable sync status, installation guidance, shared
loading/motion primitives, discovery recovery, and traffic-check integration.
Public privacy and terms pages explain optional Google coordinate processing.

## Traffic activation

Deployed `traffic-route` using its internal authenticated-user check. The Google
key was already present in Supabase. Live routes succeeded in both directions
between synthetic Guatemala place fixtures. Unauthenticated requests returned
401; a separate user without trip access returned 403. Test trip, places, and
member were soft-deleted after verification.

Fixed a live-only provider rejection by omitting explicit departureTime: Google
defaults departure to receipt time, avoiding a timestamp that is already in the
past after network latency. Updated regression assertion; all 11 traffic tests
passed. No browser or offline cache stores the Google response. Google Cloud
quota settings were not inspected; configure a daily request quota in the Google
project to enforce the desired usage limit.
